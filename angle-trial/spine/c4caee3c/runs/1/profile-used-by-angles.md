Obsidian Hybrid Search is an npm package that searches your local Obsidian vault by meaning, exact words, titles, aliases, tags, folders, links, and metadata. You can use it from an Obsidian plugin, a command-line tool, or an MCP server that lets AI agents search and read your notes. It is for Obsidian users who want to find and reuse their own notes, and for AI agents that should start from those notes and cite their source files. It runs locally by default with SQLite, and can optionally use an OpenAI-compatible embedding API instead.
