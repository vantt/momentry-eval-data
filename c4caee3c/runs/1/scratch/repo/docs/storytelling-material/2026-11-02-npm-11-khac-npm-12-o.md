# npm 11 khác npm 12 ở đầu ra npm pack: test chỉ đúng trên máy local

**Bối cảnh:** Catchup luôn đặt npm 12 lên PATH. Test gói tiếng Việt đọc đầu ra npm pack --json nhưng chỉ hiểu dạng mảng của npm 11.
**Chuyện gì xảy ra:** Test xanh trên máy local nhưng đỏ trong catchup trên CI với lỗi undefined. Sửa test để đọc cả hai dạng, rồi kiểm lại đầu ra npm 12 thật: dạng object, đủ các file dữ liệu. Lần đỏ thứ hai: test đòi build/index.js trong khi tier vi không compile gói. Sửa để chỉ kiểm package.json và các file dữ liệu.
**Bài học:** Test gọi công cụ phải được chạy đúng phiên bản công cụ mà CI dùng.
**Artefact:** Đầu ra npm pack đã rút gọn, chỉ có tên file.
